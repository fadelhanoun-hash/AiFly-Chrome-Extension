## 🎯 Quick Start: Submit Your Extension

### Step 1: Create Your Developer Account

```
1. Visit: https://chrome.google.com/webstore/devcenter
2. Sign in with Google account (create one if needed)
3. Pay $5 registration fee (one-time)
4. Wait for confirmation
```

### Step 2: Prepare Screenshots (Very Important!)

You need 5 screenshots to make your listing appealing:

**Take screenshots showing:**

1. Main messenger interface in action
2. Alt+Space hotkey activating it
3. ChatGPT/Gemini provider switching
4. Text selection popup features
5. Settings page with API key inputs

**How to take good screenshots:**

- Open AiFly on a real website (not localhost)
- Capture the messenger window clearly
- Make sure text is readable
- Show the features in action
- Suggested sizes: 640x400 or 1280x800 pixels

### Step 3: Upload Package & Complete Listing

```
1. Open Chrome Web Store Dashboard (link above)
2. Click "Create new item"
3. Upload: AiFly_submission.zip
4. Fill in store listing (use STORE_LISTING.md content)
5. Upload screenshots
6. Add privacy policy (copy from PRIVACY_POLICY.md)
7. Click "Submit for review"
```

### Step 4: Wait for Approval

- **Timeline**: 24-72 hours typically
- **What they check**: Code, functionality, privacy, compliance
- **You'll receive**: Email with approval or revision requests

## 📞 Common Questions Answered

**Q: Will my API keys be visible?**
A: No! They're stored locally in your browser only. Chrome Web Store never sees them.

**Q: Do I need to host the extension?**
A: No! Chrome Web Store hosts it for you. Users install it from the store.

**Q: Can I update it later?**
A: Yes! Use the same dashboard to upload new versions.

**Q: What if it's rejected?**
A: You'll get specific feedback and can fix & resubmit.

**Q: How do I get reviews?**
A: Ask users to rate it on the store listing. Reviews boost visibility.

**Q: Will it cost me anything ongoing?**
A: No! $5 was one-time. No hosting costs - Chrome hosts it.
