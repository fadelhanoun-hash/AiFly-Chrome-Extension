## Detailed Description (4000 character max - we'll use ~2000)

### Main Description

AiFly is a lightweight Chrome extension that brings AI assistance right to your browser. Press Alt+Space from any webpage to instantly access ChatGPT or Google Gemini—no new tabs, no switching context.

### Key Features

✨ **Instant Access** - Press Alt+Space anywhere on the web to open the AI messenger in seconds

💬 **Dual AI Providers** - Switch between OpenAI's ChatGPT and Google's Gemini with one click. Choose the AI that works best for your needs.

🧠 **Smart Formatting** - Responses include:

- Bold highlights for important terms
- Bullet points for organized information
- Tables for structured data
- Automatic medication name detection with hover popups

📋 **Advanced Text Interaction** - Select any text in responses to instantly:

- Copy to clipboard
- Create follow-up questions
- Access contextual actions

💾 **Chat History** - Your entire conversation history is saved automatically (up to 100 messages). Continue conversations anytime, anywhere.

🎚️ **Customizable Display** - Adjust font size (A+ / A-) to suit your reading preferences. Settings persist across sessions.

⌨️ **Full Keyboard Control** - Press Alt+Space to toggle, Enter to send, Escape to close. Quick, efficient, keyboard-first experience.

🔒 **Your Privacy First** - All chat history and API keys are stored securely in your browser. Nothing is sent to servers except your prompts to OpenAI or Google.

### How It Works

1. Install AiFly from the Chrome Web Store
2. Click the extension icon and go to Options
3. Enter your OpenAI or Google Gemini API key
4. Press Alt+Space anywhere to start chatting
5. Your conversations are automatically saved

### API Keys

AiFly uses YOUR OWN API keys for security and transparency:

- **OpenAI ChatGPT**: Get a free API key at https://platform.openai.com/api-keys
- **Google Gemini**: Get a free API key at https://aistudio.google.com/app/apikey

You control your keys. They're stored only in your browser.

### Privacy & Security

- ✅ No data collection by AiFly
- ✅ No tracking or analytics
- ✅ No ads
- ✅ All data stored locally on your device
- ✅ Open source and transparent

Your conversations and API keys remain completely private. See our privacy policy for details.

### Perfect For

- **Developers**: Quick code reviews, debugging, documentation
- **Writers**: Grammar checking, brainstorming, content ideas
- **Students**: Research assistance, explanations, problem solving
- **Professionals**: Quick answers, email drafting, task automation
- **Everyone**: Any quick question while browsing

### Permissions Explained

- **storage**: To save your chat history and API keys locally
- **scripting**: To run the AI messenger interface
- **activeTab**: To know which tab you're on
- **\<all_urls\>**: To work on any website

All permissions are necessary for core functionality and respect your privacy.
